# GiveTrack website

## Run locally
1. Keep `index.html`, `style.css`, `script.js`, and `givetrack-logo.png` in the same folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. An internet connection is required for Google Fonts, Tailwind CDN, Chart.js, and Lucide icons.

## Included
- Responsive NGO dashboard and navigation
- Campaign cards and demonstration donation modal
- Donation transparency doughnut chart and reconciled totals
- Recent donations table with CSV export
- Volunteer opportunities and skill/availability matching assistant
- Supplied GiveTrack logo used in header and footer

## Demo behaviour
The initial dashboard figures are sample data. A demo donation updates the dashboard totals, campaign progress, and donation table in the current page session only. No payment is taken and no data is sent to a server. Refreshing the page restores the original sample data.
